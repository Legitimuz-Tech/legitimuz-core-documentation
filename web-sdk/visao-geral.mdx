Todos os caminhos montam o mesmo widget e recebem os mesmos eventos. A escolha é sobre o seu stack,
não sobre funcionalidade.

| Método | Como carrega | Melhor para |
| --- | --- | --- |
| Pacote npm | `npm install @legitimuz/websdk` | Projetos com bundler (qualquer framework ou vanilla) |
| CDN | `<script>` que expõe `window.Legitimuz` | Páginas sem build, CMS, landing pages |
| Wrapper React | `@legitimuz/websdk-react` | Apps React e Next.js |

Com o pacote npm, importe `mount()` e chame com as [opções](/web-sdk/opcoes); a função só precisa
de um elemento para renderizar e funciona em qualquer framework. O CDN expõe a mesma API sem
instalação, e o script é evergreen: a URL `v1` serve sempre a última versão sem breaking change. O
wrapper React resolve o ciclo de vida (montagem, `destroy()`, callbacks atualizados) por você, como
descrito em [usar com React](/web-sdk/react).

Em Vue, Svelte ou Angular, use o pacote npm e, se preferir escutar no template, os
[eventos DOM](/web-sdk/eventos#eventos-dom) do elemento que o `mount()` cria.

para eles.
